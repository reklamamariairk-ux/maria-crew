# Поставить «Мария · Админ» на iPhone через Sideloadly

Sideloadly ставит приложение на твой iPhone под **бесплатным Apple ID** — без App Store,
без Apple Developer ($99), без ревью. Подходит для «поставить себе / паре руководителей».

**Как это работает:** Sideloadly не компилирует приложение — он берёт готовый `.ipa`,
переподписывает его твоим Apple ID и заливает на телефон по USB. Скомпилировать iOS-`.ipa`
можно только на macOS, поэтому `.ipa` собираем один раз в облаке (Мака у нас нет).

```
[облако macOS: собрать unsigned .ipa]  →  [скачать .ipa на ПК]  →  [Sideloadly: подпись + установка на iPhone]
```

---

## Шаг 1. Получить unsigned .ipa (один раз, ~10 мин)

### Вариант A — Codemagic (проще, готово в репо)
1. Зайти на **codemagic.io** → Sign up with GitHub → разрешить доступ к репозиторию `maria-crew`.
2. В списке приложений выбрать maria-crew → он подхватит `mobile-admin/codemagic.yaml`.
3. Запустить workflow **«Мария Админ — iOS unsigned (Sideloadly)»** (`ios-unsigned`).
   Сертификаты/логины Apple вводить НЕ надо — сборка неподписанная.
4. Когда позеленеет — скачать артефакт **`MariaAdmin-unsigned.ipa`**.

Бесплатного тарифа Codemagic (500 мин/мес) хватает с запасом.

### Вариант B — GitHub Actions (бесплатно, но нужен токен с workflow-правами)
Готовый workflow лежит локально в `.github/workflows/ios-admin-unsigned.yml`, но запушить
его сохранёнными токенами нельзя (нет `workflow`-scope). Если хочешь этот путь:
добавь файл через веб GitHub (репозиторий → **Add file → Upload files** → перетащить
`.github/workflows/ios-admin-unsigned.yml` → Commit) → вкладка **Actions** → workflow
«iOS Admin — unsigned IPA» → **Run workflow** → скачать артефакт `MariaAdmin-unsigned-ipa`.

## Шаг 2. Подготовить Windows и iPhone

**На ПК:**
1. Поставить **iTunes** и **iCloud** — версии с **сайта Apple** (apple.com), НЕ из Microsoft
   Store. Sideloadly видит устройство только через desktop-версии (драйвер Apple Mobile Device).
2. Скачать **Sideloadly** с **sideloadly.io**, установить, перезагрузить ПК.

**На iPhone (iOS 16 и новее):**
3. Настройки → Конфиденциальность и безопасность → **Режим разработчика** → включить →
   перезагрузить телефон, подтвердить. (Пункт появляется после первой попытки установки,
   если его сейчас нет — вернись к нему после Шага 3.)

## Шаг 3. Установить приложение

1. Подключить iPhone к ПК кабелем, на телефоне нажать **«Доверять этому компьютеру»**.
2. Открыть **Sideloadly**. Вверху появится твой iPhone (Device).
3. В поле **Apple ID** ввести свой Apple ID (обычный, бесплатный). Пароль спросит при старте —
   если включена 2FA, сгенерируй **app-specific password** на appleid.apple.com и введи его.
4. Перетащить в окно файл **`MariaAdmin-unsigned.ipa`**.
5. Нажать **Start**. Sideloadly сам:
   - создаст бесплатный provisioning-профиль,
   - подставит уникальный Bundle ID (напр. `ru.mariairk.crew.admin.<хвост>`) — так надо
     для бесплатного аккаунта, на работу не влияет,
   - подпишет и зальёт на телефон. Готово, когда статус «Done».

## Шаг 4. Доверить сертификат на iPhone

Настройки → Основные → **VPN и управление устройством** → под «Профиль разработчика»
выбрать свой Apple ID → **Доверять**. После этого иконка «Мария · Админ» запускается.

Приложение сразу откроет живую админку `crew.145-223-121-47.sslip.io` — логинишься как обычно.

## Важно про бесплатный Apple ID

- **Срок жизни подписи — 7 дней.** Через неделю приложение перестанет запускаться —
  надо снова открыть Sideloadly с подключённым телефоном и нажать Start (переподпишет,
  данные/сессия не теряются). Sideloadly умеет напоминать/делать это авто-режимом.
- Лимит: **3 своих приложения** одновременно на бесплатном ID.
- Нужно раздать нескольким руководителям без 7-дневной возни → тогда всё-таки
  **Apple Developer ($99/год)**: подпись на 1 год + путь TestFlight/Unlisted (см. `SETUP_GUIDE.md`).
- Альтернатива переподписи по кабелю — **AltStore/SideStore** (обновляет подпись по Wi-Fi сам),
  тоже работает с этим `.ipa`.

## Если приложение не ставится
- «Unable to install / MDM» — проверь Режим разработчика (Шаг 2.3) и что iTunes/iCloud с сайта Apple.
- Крашится при запуске — не доверен профиль (Шаг 4) либо истекли 7 дней (переподписать).
- Sideloadly не видит iPhone — переустанови iTunes/iCloud с apple.com, другой USB-порт/кабель.
